# NEXORA — AI-Powered Career Discovery Platform

> **"Find work that moves you forward."**  
> Built for the **Acdyon Technologies Frontend Challenge**.

NEXORA is a modern, high-performance web platform designed to streamline career discovery. It replaces generic templates and static landing pages with a dynamic, product-first experience featuring interactive AI job matching, live resume scanning simulation, career trajectory analytics, and an integrated application pipeline tracker.

---

## ✨ Features

- **🚀 Interactive Hero & 3D Scroll Showcase:** Scroll-driven dashboard reveal with smooth perspective transitions and interactive preview states.
- **🎯 Dynamic AI Match Scoring Engine:** Interactive skill alignment calculator assessing domain expertise, tech stack, and role compatibility.
- **📄 Live Resume Analyzer:** Simulated resume scanner highlighting strengths, identified gaps, and actionable suggestions.
- **📊 Real-Time Career Intelligence:** Market salary benchmarks, hiring demand metrics, and trajectory visualizations.
- **📋 Integrated Application Tracker:** Interactive kanban-style pipeline to monitor interview stages and status updates.
- **💎 Honest Capability Pillars:** Three core capability pillars (**DISCOVER**, **UNDERSTAND**, **MOVE FORWARD**) focusing on authentic product value.
- **🎨 Modern Design System & Theme Support:** Dark and light mode support built with Tailwind CSS v4, Geist typography, and refined micro-interactions.
- **🕹️ Secret Easter Egg:** Try entering the **Konami Code** (`↑ ↑ ↓ ↓ ← → ← → B A`) or clicking the logo 5 times to unlock *Founder Mode*.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.18+ or v20+)
- `npm`, `pnpm`, or `yarn`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RitikRai07/Acdyon-Technologies-Frontend-Challenge.git
   cd Acdyon-Technologies-Frontend-Challenge
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).

---

## 📦 Production Build

To test the production build locally:

```bash
npm run build
npm run start
```

## 🌐 Deploying to Vercel

This project is fully optimized for **zero-config deployment on [Vercel](https://vercel.com/)**:

1. Push your code to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New..." > "Project"**.
3. Import the `Acdyon-Technologies-Frontend-Challenge` repository.
4. Vercel automatically detects **Next.js**:
   - **Framework Preset:** `Next.js`
   - **Build Command:** `npm run build` (or `next build`)
   - **Output Directory:** `.next`
5. Click **Deploy**.
